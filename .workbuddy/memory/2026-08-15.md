### 【VT-x 释放排查（重启后仍无效）】
- 用户重启后 VBox 仍 `VT-x is not available` → NEM。排查发现：
  - `bcdedit /enum {current}` **无 hypervisorlaunchtype 项**（默认 auto）→ 之前告知的命令没生效。
  - **VBS 状态 = enabled+locked**（DeviceGuard 注册表 EnableVirtualizationBasedSecurity 已=0 但仍锁定运行）——locked 态注册表改 0 无效，且 `WasEnabledBy=1`（UEFI 锁定）。
  - **VirtualizationFirmwareEnabled=False** → BIOS 里 Intel VT-x 很可能没开（i5-1155G7 笔记本出厂可能默认关）。
  - 脚本 `关闭Hyper-V释放VT-x.bat`（bcdedit off + reg 关 VBS/HVCI）用户没跑成功（结果文件不存在）。
- **QEMU WHPX 测试**：`-accel whpx` 32 位内核完整启动（比 NEM 强）但 switch64 崩：`WHPX: Unexpected VP exit code 4` —— WHPX/NEM 同为 Hyper-V API，NexOS 自建页表 long-mode 切换都不兼容。
