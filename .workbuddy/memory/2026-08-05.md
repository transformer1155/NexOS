## 浏览器引擎强化 (Chrome-like) — 任务启动

用户要求给 MiniOS 原生浏览器加「真实 Chrome 内核」能力。已澄清:32位 freestanding
内核(无 libc/线程/GPU,内核 256KiB 上限)无法嵌入真实 Chromium,改为大幅强化原生引擎。
用户选了 4 个方向 + IDM式下载 + Steam++式访问。

### 重大发现: gui.cpp 之前根本无法编译
- `Win11Desktop` 结构体(1293–4300)内非法嵌套了 `namespace browser`(2930–3360)。
  C++ 不允许在 class 内定义 namespace,导致 `make` 一直失败(此前被 net.cpp 编译错误掩盖)。
- 同文件另有两处预存 bug(被掩盖未暴露):render() 中属性解析 `r=='\t'` 应为 `*r=='\t'`
  (指针/整数比较);以及 browser 引用 `g_wm.windows[id]` 时 g_wm 尚未完整定义。
- kernel.cpp/kernel64.cpp 缺 `memcpy/memset/memmove`(freestanding 下 -O2 生成 builtin
  调用导致链接 undefined reference)。

### 已修复(使整体可编译/链接)
- 用 Python 脚本把 `browser` namespace 从 Win11Desktop 结构体内移到匿名命名空间顶层
  (置于 struct 之前),并把 `browser::draw` 改为接收 `Win11Window& win` 参数
  (由 draw_browser 传入 `windows[id]`),消除对 g_wm 的依赖。
- 修正 render() 指针比较 bug。
- 在 kernel.cpp / kernel64.cpp 增加 `extern "C" memcpy/memset/memmove` 实现。

### 已完成:任务#65 网络层强化 (net.cpp)
- HTTP 3xx 重定向透明跟随(限 5 跳,支持绝对/根相对/目录相对 Location)。
- Transfer-Encoding: chunked 分块解码(httpc_decode_chunked)。
- Content-Type / 状态码识别,新增 `browser_content_type()` / `browser_status_code()`
  公开 API(kernel.cpp 已声明)。
- TLS/HTTPS 受 32位内核限制,作为文档化限制暂不实现。

## 窗口管理器强化 (任务#70–#73) — 已完成

用户要求:默认搜索引擎改 Bing、窗口全屏/悬浮/最小化、按钮命中检测(z-order)、
Win11 开始菜单 + 关机功能。全部在 gui.cpp / kernel.cpp / kernel64.cpp 实现。

### #70 默认搜索引擎 → Bing
- `browser::g_search` 由 `https://duckduckgo.com/html/?q=` 改为
  `https://www.bing.com/search?q=`;HOME_HTML 与引擎下拉列表顺序/文案同步更新。

### #71 窗口全屏/悬浮/最小化
- `Win11Window` 新增 `minimized / fullscreen / floating` 标志 + `restore_x/y/w/h`。
- 标题栏从仅「关闭」扩为 4 个按钮:关闭(X)/全屏(M)/最小化(_)/置顶(T),
  几何统一由 `title_btn_rect(which,bx,by)` 计算(0=close 1=fullscreen 2=min 3=float)。
- `toggle_fullscreen(i)`:全屏覆盖整个屏幕(含压住任务栏),跳过阴影/圆角。
- 任务栏条目点击:激活窗口→再点则最小化;已最小化→点则恢复。

### #72 按钮命中 z-order(修复「被遮住的按钮被误点」)
- 重写 handle_mouse_down 的窗口命中循环为严格 z-order:
  1) floating 窗口永远最上(逆序) 2) active 窗口 3) 非 floating 非激活(逆序)。
- 提取 `window_click(i)` 处理标题按钮/拖拽/内容点击,仅当命中窗口才 consume。
- render_all 绘制顺序同步:普通非激活→普通激活→floating非激活→floating激活。

### #73 Win11 开始菜单 + 关机
- `draw_start_menu` 改为 Win11 风格:380x248 面板,Pinned 4×2 应用磁贴网格 + 底部
  电源栏(Shut down / Restart)。
- `GuiCallbacks` 新增 `shutdown / reboot` 回调(gui.cpp 与 kernel.cpp/kernel64.cpp
  两处 struct 定义必须保持字段顺序一致,否则 `g_cb=*cb` 布局错乱);
  kernel.cpp/kernel64.cpp 的 `register_gui_callbacks` 接到 `cmd_shutdown/cmd_reboot`
  (ACPI outw 端口断电 / 键盘控制器复位重启)。
- 开始菜单命中逻辑同步:电源按钮调 `g_cb.shutdown()/g_cb.reboot()`。
