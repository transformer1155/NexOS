项目介绍

NexOS 是一个教学级全栈操作系统：以自研 C++ 内核为底座，融合 C# 托管桌面壳、 浏览器 Web 控制台、本地 Qwen2 GGUF 推理引擎与 distnet / dcn 分布式算力运行时， 并支持运行 Windows（PE/Win32）、Linux 与 .NET 程序。

🪟 内核与引导

Stage1→Stage2 二阶引导，32 位保护模式与 64 位长模式双内核，BIOS/UEFI 双路径汇合到同一 C++ 入口。

🎨 图形桌面

帧缓冲上自绘 Win11 风格桌面，叠加 C# 托管壳（NexOS.Forms / NexOS.Core）实现窗口管理器。

🌐 Web 控制台

浏览器端 Win11 桌面 + Agent Forge，经 WebSocket 桥直连真实 QEMU 内核。

🧠 AI 推理

内置 Qwen2-0.5B GGUF Transformer 推理引擎，支持 64 位流式推理与智能体。

⚡ 分布式算力

UDP 发现 / 调度，将推理与计算任务分片下发到多节点合并执行。

🔌 兼容层

自研 PE/Win32 子系统、Linux 二进制兼容、Mono/.NET 运行时移植。
