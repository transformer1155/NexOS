# Notepad 交互逻辑规格 (v2.0 - 对表 Windows)

> 本文档描述 Notepad 作为**独立应用**（`Notepad.mex`，运行在独立 CLR 槽）的全部交互契约。>  
> 本文档已基于 Windows 11 / Win32 记事本的基准行为进行校准（对表），并针对 NexOS 资源受限环境做了防崩溃约束。



---

## 0. 运行形态

| 项     | 约定                                             |
| ----- | ---------------------------------------------- |
| 程序集   | `Notepad.mex`（独立，约 34 KB）                      |
| CLR 槽 | 非 0 槽（shell 占槽 0）                              |
| 入口符号  | `App.Main::Init / Paint / Click / Key / Title` |
| 窗口归属  | `mforms_set_window_slot(win, slot)`            |
| 依赖    | 仅 `NexOS.Forms`，**不依赖 Shell/Desktop**          |

**核心约束**：每窗口一次 `Init`；`Paint` 每帧由内核 GUI 循环调用。**多窗口之间完全隔离**，各自拥有独立的文本缓冲区和撤销栈，严禁跨窗口共享内存数据。

---

## 1. 窗口

| 属性   | 值                                          |
| ---- | ------------------------------------------ |
| 默认尺寸 | 640 x 480                                  |
| 最小尺寸 | 320 x 200                                  |
| 标题   | `Notepad - <文件名>`；未命名 `Notepad - Untitled` |
| 保存后  | 标题追加 ` (saved)`，下次编辑操作后立即清除                |
| 多实例  | 允许（任务栏右键 -> New window），各窗口数据独立互不干扰        |

## 2. 布局

```
y=0   +------------------------------------------+
      | [Open] [New] [Save As]  <文件名>  (saved) | h=36  工具栏
      |                         <格式标签>        | h=20  第二行
y=56  +------------------------------------------+
      |                                          |
      |            文本区（带垂直滚动条）             |
      |                                          |
      +------------------------------------------+
      | 状态栏：Ln X, Col Y | X chars | Target: Z  | h=22
      +------------------------------------------+
```

- 工具栏按钮固定宽 **70 px**，间距 10 px
- 文本区左边距 8 px，行高 20 px  
  |  |  |  |  
  | --- | --- | --- |
- 状态栏按 Windows 标准显示基础信息：`Ln 行号, Col 列号 | 字符数 chars | Target: 保存路径`

## 3. 鼠标交互

| 区域          | 左键                  | 右键         |
| ----------- | ------------------- | ---------- |
| **Open**    | 打开文件选择器             | -          |
| **New**     | 清空文本，标题 -> Untitled | -          |
| **Save As** | 打开保存对话框             | -          |
| **文本区**     | 定位光标；拖拽选择           | 上下文菜单（见 5） |
| **垂直滚动条**   | 拖动 / 点击轨道翻页         | -          |
| **状态栏**     | -                   | -          |

**双击**：文本区双击选中单词（以空格或标点符号为界）。  
**脏数据标记 (Dirty Flag)**：任何修改文本的操作（输入、删除、粘贴、撤销/重做）必须将 `isDirty` 置为 `true`；成功保存后置为 `false`。

## 4. 键盘交互

### 4.1 编辑 (防冲突约束)

| 键           | 行为                                         |
| ----------- | ------------------------------------------ |
| 可打印字符       | 插入                                         |
| `Enter`     | 换行                                         |
| `Backspace` | 删除前一个字符                                    |
| `Delete`    | 删除光标后字符                                    |
| `Tab`       | **插入 4 个空格**（必须拦截默认的焦点切换行为并 `return true`） |
| `Ctrl+A`    | 全选                                         |
| `Ctrl+C`    | 复制                                         |
| `Ctrl+V`    | 粘贴                                         |
| `Ctrl+X`    | 剪切                                         |
| `Ctrl+Z`    | 撤销（限制栈深度最多 100 步，防内存撑爆）                    |
| `Ctrl+Y`    | 重做                                         |

### 4.2 文件

| 键              | 行为             |
| -------------- | -------------- |
| `Ctrl+S`       | **原地保存**到文件来源卷 |
| `Ctrl+Shift+S` | 打开 **Save As** |
| `Ctrl+O`       | 打开文件选择器        |
| `Ctrl+N`       | 新建             |

### 4.3 光标与选择

| 键                        | 行为          |
| ------------------------ | ----------- |
| `Left` / `Right`         | 移动一字符       |
| `Up` / `Down`            | 移动一行（保持列位置） |
| `Home` / `End`           | 行首 / 行尾     |
| `Ctrl+Home` / `Ctrl+End` | 文首 / 文末     |
| `PageUp` / `PageDown`    | 翻页          |
| `Shift+方向键`              | 扩展选择        |
| `Ctrl+Shift+方向键`         | 按词扩展选择      |

**中文排版注意**：光标移动、列号计算（Col）时，必须计算字符的**显示宽度**（中文字符占 2 宽），而不是简单的字符长度，防止中英混排时光标乱飘。

### 4.4 窗口

| 键        | 行为                                      |
| -------- | --------------------------------------- |
| `Esc`    | 关闭当前对话框；无对话框时不做事                        |
| `Alt+F4` | 触发关闭窗口逻辑（若 `isDirty` 为 true，走第 7 节拦截提示） |

## 5. 上下文菜单（文本区右键）

严格按以下菜单树实现，并支持状态灰化（如无剪贴板内容则 Paste 灰化，撤销栈空则 Undo 灰化）。

```
Undo                 Ctrl+Z
Redo                 Ctrl+Y
------------------
Cut                  Ctrl+X
Copy                 Ctrl+C
Paste                Ctrl+V
Delete               Del
------------------
Select All           Ctrl+A
------------------
Word Wrap            [x] (默认勾选)
------------------
Save                 Ctrl+S
Save As...           Ctrl+Shift+S
```

## 6. 文件选择器（Open）

```
+--------------------------------------+
| Open file                            |
| Volume: [MKFS root] [SFS] [Desktop]  |
| Folder: /plugins                     |
| ----------------------------------- |
|  [D] Desktop                         |
|  F  hda_trace.txt                    |
|  F  plugins.lst                      |
|  ...                                 |
| ----------------------------------- |
|            [Open]  [Cancel]          |
+--------------------------------------+
```

- 双击文件 = 直接打开；双击目录 = 进入；`..` 行回到上级。
- 列表最多 **12 行**，超出通过滚动条操作。
- **SFS 卷**：允许浏览，但只读卷内的文件在列表中**必须灰化**，双击无效。

## 7. 保存与关闭逻辑

### 7.1 保存对话框（Save As）

```
+------------------------------------------+
| Save as - choose a location and a name    |
| Volume: ( ) MKFS root   (o) Desktop       |
| Folder: Desktop/                          |
| File name: [Untitled.txt          ]       |
| Detected content: Plain text              |
| ----------------------------------------  |
|              [Save]   [Cancel]            |
+------------------------------------------+
```

- **卷选择**：只列**可写**卷：MKFS root(0)、Desktop(3)。
- **自动补后缀**：无扩展名时，根据内容探测自动追加（见第 8 节）。
- **同名冲突**：必须弹出确认对话框：“`文件名` 已存在。是否要替换它？”（【是】/【否】）。选择【否】退回保存对话框。
- **保存失败**：显示红色提示，对话框保持打开状态。

### 7.2 关闭拦截逻辑（未保存提示）

点击关闭按钮或 `Alt+F4` 时，若 `isDirty == true`，必须弹出经典三选项对话框：

- 【保存】：执行保存逻辑，成功后关闭窗口。
- 【不保存】：直接丢弃内存中的修改，关闭窗口。
- 【取消】：忽略关闭请求，回到编辑界面。

## 8. 内容格式与容错识别

| 特征                         | 标签                     | 后缀      |
| -------------------------- | ---------------------- | ------- |
| `{rtf`                     | Rich Text (RTF source) | `.rtf`  |
| `<?xml`                    | XML markup             | `.xml`  |
| `<!DOCTYPE html` / `<html` | HTML document          | `.html` |
| `{`                        | JSON data              | `.json` |
| `;;` 或 `; `                | INI / config           | `.ini`  |
| `---` 或行首 `#`              | Markdown               | `.md`   |
| 其他                         | Plain text             | `.txt`  |

**对表优化（极重要）**：

> 文件打开时，扫描前 **1024 个字节**。若包含 NUL (`\0`)、非文本控制字符或 `0x7F`，**立即拒绝打开**，并弹窗提示“无法打开文件：不支持的二进制格式”。>  
> *(注：为保证主线程不卡死，不在内核层实现庞大的十六进制视图渲染器)*。

## 9. 自动换行（Word Wrap）引擎约束

由于原文档未详细说明 Word Wrap，此处强制对表 Windows 行为：

1. **默认状态**：开启（勾选）。
2. **开启时**：文字到达窗口右边缘自动折行，隐藏水平滚动条。`Home`/`End` 键作用于视觉行。
3. **关闭时**：文字不折行，出现水平滚动条，单行无限延伸。
4. **切换动作**：切换该选项时，必须触发整个文本区重绘 (`Repaint`)，并重算滚动条范围。
